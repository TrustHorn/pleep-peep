# Локальный UI pleep-peep

Три экрана по техническому заданию, React + Next.js + Tailwind CSS.

## Запуск

```sh
pnpm install
pnpm dev
```

Открыть http://localhost:3000.

- `/` и `/dashboard` — один экран обзора: метрики, график, карточки публикаций, темы и TXT-экспорт.
- `/competitors` — поиск, платформы, сортировка, добавление и просмотр аккаунтов.
- `/ai-studio` — бриф, примеры идей, редактирование сценария, черновики, копирование и TXT-экспорт.

Вся логика работает в браузере на демонстрационных данных. Бэкенда, API, базы данных и реальной AI-генерации нет. Список конкурентов сохраняется в памяти до перезагрузки страницы, черновики — в localStorage этого браузера. Черновики можно удалить в окне «Мои черновики».

## Проверка и статическая сборка

```sh
pnpm build
pnpm typecheck
```

`pnpm build` создаёт статические HTML/CSS/JS-файлы в `out/`. Для работы интерфейса не нужен сервер Next.js. Шрифты системные, внешние изображения и сетевые сервисы не используются.
